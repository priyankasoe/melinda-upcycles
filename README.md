# Melinda Upcycles

Static one-page shop site for Melinda Upcycles.

## Local preview

Open `index.html` in a browser. No build step is required.

## Order form

The order section embeds this Google Form:

```text
https://docs.google.com/forms/d/e/1FAIpQLSd_TajrTkskWyVPr92_fwwdVXIuC5BaPI_NsI0eacnYeDd29A/viewform
```

To receive submission notifications at `prisoe36@gmail.com`:

1. Open the form while signed in as `prisoe36@gmail.com`, or add that account
   as a form editor.
2. Go to the form's `Responses` tab.
3. Open the three-dot menu.
4. Turn on `Get email notifications for new responses`.

Google's built-in notifications alert the subscribed editor when a new response
arrives. If the email needs to include every submitted answer in the body, use a
Google Forms notification add-on or an Apps Script connected to the response
sheet.
